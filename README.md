# Athena Chang | Portfolio Website
A portfolio website built with HTML, CSS, and JavaScript. This site is a dedicated space introducing me, showcasing my work, and providing my contact information.

### Features:
- Responsive navigation bar with a hamburger menu with mobile compatibility
- Projects section featuring my work

### Tech Stack:
- HTML5
- CSS3
- Vanilla JavaScript
- [Font Awesome](https://fontawesome.com) for icons
- [Google Fonts Kumbh Sans](https://fonts.google.com/specimen/Kumbh+Sans?preview.script=Latn)

### Installation:
1. Clone the repository
```
git clone <repository-url>
```
3. Open index.html directly in browser, or with simple static server (e.g., VS Code Live Server extension)
