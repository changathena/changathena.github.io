# Athena Chang | Portfolio Website
A static portfolio website built with HTML, CSS, and JavaScript. This site is a dedicated space introducing me, showcasing my work, and providing my contact information.

## Getting Started
1. Clone the repository
```
git clone <repository-url>
```
3. Open index.html directly in browser, or with simple static server (e.g., VS Code Live Server extension)

Naming the repository `<username>.github.io` allows the usage of GitHub Pages, meaning the site is already deployed at [https://changathena.github.io/](https://changathena.github.io/). 

## Usage
To swap in your assets, follow the instructions below:
1. Insert your resume PDF at `images/resume_02.pdf`
2. Insert your headshot at `images/portrait.png`
3. Update the image paths in `main.js`

## Tech Stack:
- HTML5
- CSS3
- Vanilla JavaScript
- [Font Awesome](https://fontawesome.com) for icons
- [Google Fonts Kumbh Sans](https://fonts.google.com/specimen/Kumbh+Sans?preview.script=Latn)
