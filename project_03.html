About

Using Python, I developed a program that loads an image as a NumPy array and computes the mean intensity per RGB channel.

I implemented sRGB gamma decoding (normalizating and piecewise linearization) for accurate brightness calculations.

Built modular functions for normalization, linearization, and averaging; handled grayscale input and tested on RGB and grayscale cases.
